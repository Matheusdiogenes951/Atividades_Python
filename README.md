📘 Atividades Python – Curso em Vídeo

Este repositório contém a resolução dos exercícios propostos durante o curso de Python do Curso em Vídeo, ministrado pelo professor Gustavo Guanabara.

O curso é dividido em três módulos principais:

Módulo	Conteúdo
Python Mundo 1	Fundamentos da linguagem, variáveis, entrada/saída de dados, condicionais simples e compostas
Python Mundo 2	Estruturas de repetição (while e for), listas, tratamento de dados e laços mais complexos
Python Mundo 3	Funções, modularização, dicionários e aprofundamento na lógica de programação

As atividades foram organizadas em pastas separadas conforme o mundo a que pertencem:

📁 python_mundo1/
📁 python_mundo2/
📁 python_mundo3/

Registrar minha evolução na linguagem Python, mantendo um histórico de estudos e servindo como consulta futura para mim e para outros estudantes que estejam iniciando na programação.
